Yuyuan Yuan is a Senior Software Engineer at ZettaScale Technology, where he contributes to Zenoh, an open-source Rust protocol for pub/sub, queries, and distributed storage spanning edge to cloud environments.
He works on Hiroz, a pure-Rust, Zenoh-native ROS 2 middleware, and is a committer to both Eclipse Zenoh and ros2/rmw_zenoh, the official Zenoh-based RMW for ROS 2. His work focuses on protocol design, asynchronous runtime architecture, and multi-language bindings built on a Rust core, including Python (via PyO3) and Go (via C FFI).
