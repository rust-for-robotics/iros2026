Florian Gilcher is managing director and co-founder of Ferrous Systems GmbH. He has worked with the Rust programming language since 2013, co-founded the Rust Foundation, and served for many years as project director and Core Team representative on the Foundation's board of directors. He has been instrumental in advancing Rust for use in safety-critical software with the creation of Ferrocene, the open source, qualified Rust compiler toolchain for safety- and mission-critical applications. A strong advocate for the Rust project and its global community, he regularly supports the language through training, public speaking, organizing meetups and open source contributions.
